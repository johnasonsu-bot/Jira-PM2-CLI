# Forge Local MCP Implementation Plan

> **For agentic workers:** Use inline execution with superpowers:executing-plans. User requested autonomous completion without stepwise confirmation.

**Goal:** Install a read-only local Forge MCP and prove developer workload ranking through a real Codex client.

**Architecture:** Reuse Backend and the existing analytics API. A stdio SDK server exposes typed read-only tools; a pure rank_report function derives the ranking from an API report.

**Tech Stack:** Python 3.10+, mcp>=1.28,<2, pytest, existing SQLite HTTP app, installed Codex CLI.

**Spec:** ../specs/2026-09-07-local-mcp-design.md

## Global Constraints

- No new database, exposed port, secrets, mutation tools or shell gateway.
- Current workload is not performance or hours; unassigned and completed-only owners are not ranked.
- Leave original repository and unrelated PM2/configuration entries unchanged.
